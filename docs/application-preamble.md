# Welcome to Carrot CLI

Carrot CLI is a guided Windows command-line client for preparing documents for the Carrot 4.8.6 Document Clustering Server. The completed workflow will discover supported documents, extract searchable text, request topic clusters, and produce reviewable Excel and JSON results.

## Getting Started

1. Select **Process Documents** to prepare a complete clustering and reporting run.
2. Select **Preview Request** to inspect the planned request without submitting it.
3. Select **Server Information** to inspect server algorithms, languages, and templates.
4. Select **Help** from any menu for detailed guidance.

The operational workflows are still being built. Selecting **Execute** currently displays `Pending Implementation` without reading documents, contacting a server, or writing output.
