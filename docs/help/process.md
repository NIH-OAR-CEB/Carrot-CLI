# Process Documents

The future process workflow will discover documents, extract searchable text, submit one clustering request, and write Excel and JSON artifacts.

Supported inputs are a folder or ZIP archive. The future interactive setup will ask for input, endpoint, clustering, and output settings before execution.

In the current UI milestone:

- **Execute** displays `Pending Implementation` without reading files or contacting a server.
- **Help** displays this topic.
- **Back to Main Menu** leaves the workflow without side effects.

Use `carrot-cli help commands-options` for the planned noninteractive options.
