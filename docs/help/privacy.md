# Privacy

Document content will be sent to the configured Carrot server when processing is implemented. Confirm that the server and network path are approved for the source material.

- Interactive endpoint values are not persisted.
- Request JSON artifacts will contain full extracted document text unless explicitly disabled.
- Response JSON artifacts will contain the complete clustering response.
- Logs and Excel output can include source paths, file metadata, previews, and failure details.

Protect output folders and artifacts according to the sensitivity of the source documents.
