# Getting Started

Run `carrot-cli` without arguments to open the interactive menu.

1. Select **Process Documents**, **Preview Request**, or **Server Information**.
2. Select **Help** on any workflow menu for focused guidance.
3. Select **Execute** to exercise the initial UI route. Operational workflows currently display `Pending Implementation`.
4. Select **Back to Main Menu** or **Exit** when finished.

For noninteractive syntax, run:

```text
carrot-cli --help
carrot-cli help commands-options
```

Noninteractive processing is reserved for a later implementation milestone.
